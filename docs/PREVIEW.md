# Изолированное превью Niri + GTK4

Внутри работающей Wayland-сессии NixOS: `nix develop --command task dev:preview`. Команда компилирует только Rust, создаёт временную конфигурацию для вложенного Niri и запускает отдельные Core и Shell с отдельным Unix socket. Никаких HTML, Vite и WebKit.

Закрытие: Alt+Shift+Q во вложенном Niri или Ctrl+C в терминале. Временные файлы удаляются. Запрещено изменять конфигурацию родительского Niri, запускать системную замену DE и выдавать наличие GTK-окна за полноценную визуальную приёмку.

Перед выпуском вручную проверить фокус, реальные workspace, минимум два монитора, разные масштабы, popups и тайм-ауты. [MIGRATION_NATIVE_GTK.md](MIGRATION_NATIVE_GTK.md) содержит незакрытые этапы.
