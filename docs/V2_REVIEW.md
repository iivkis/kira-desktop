# Kira Desktop V2 — ревью спецификации и очистка

**Дата:** 2026-11-07 · **Ветка:** `kira-desktop-v2`

Это **статический аудит** документации, дерева файлов, манифестов и CI; нативная V2 сборка и GPU-тесты не выполнялись.

## Заключение

Lua → Rust source compiler → native GTK4 — реалистичная концепция **для ограниченного статически проверяемого Lua DSL**. Перевод полного динамического Lua в статический Rust без интерпретатора не является обещанием V2.

## Что исправлено

1. Разделены действующая реализация V1 и целевой V2, сокращён корневой README.
2. Добавлен нормативный [Lua Language v0](V2_LANGUAGE.md): формы AST, типы, State/Bind, обработчики, безопасность и ограниченный GTK CSS.
3. Уточнены допущения по build-time codegen, отсутствию Lua VM, детерминированности, а также тому, что GTK UI должен обновляться из main context.
4. V1 документы размечаются как миграционные справочники; их техническая ценность и тесты остаются.
5. Из ветки удалены **сгенерированный `.repospool` (1,4 МБ), `.repospoolignore` и workflow его публикации**. Они относятся к старому контекстному снапшоту, а не к разработке компилятора V2.
6. Добавляются статические тесты согласованности V2 документов в существующие Taskfile/CI/Nix проверки.

## Что не удалено намеренно

`frontend/`, `crates/kira-shell/`, npm lock, WebKitGTK, GSAP, legacy CI/tests/Nix pipeline. Они пока реально используются: удаление до GTK replacement разрушит регрессионную основу. Это **не целевые зависимости V2**.

## Открытые риски

- **P0:** нет `kira-lua-compiler` и GTK-only версии Shell, пример Lua пока не исполняется.
- **P0:** защита кодогенератора от недоверенного Lua и корректная типовая семантика не реализованы.
- **P0:** отсутствуют настоящие GTK/Wayland/Niri V2 smoke и E2E тесты.
- **P1:** понадобятся расширения DSL для сложных виджетов, событий и системных API.
- **P1:** память/производительность GTK без WebKit пока не измерены.
- **P1:** TENET motion нуждается в отдельном native Rust/GTK контракте.
- **P2:** Cargo декларирует MIT, но отдельного корневого `LICENSE` нет. Правообладателя нужно подтвердить, а не выдумывать в процессе уборки.

## Следующая точка приёмки

`examples/v2/counter.lua` → parser → typed IR → generated Rust + GTK CSS → нативное GTK4 окно без Lua VM/WebKit. До этого старый green CI подтверждает **только V1 и целостность документации V2**.
